# 🌍 Tourism Intelligence Dashboard

Interactive Streamlit dashboard for analysing Spanish outbound tourism demand (Jul 2019 – Dec 2025).

## Data sources
- **INE** Experimental Mobility Statistics (main traveller flows)
- **DataForSEO** Monthly search volumes
- **Google Trends** Trend index signals

## Run locally

```bash
pip install -r requirements.txt
streamlit run app_tourism.py
```
